# Input
Drop files here for the agent to work on: refusal letters, GCMS notes, procedural fairness letters, client questionnaires, draft packages.

- One subfolder per client or task is easiest: `Input/<surname>-<program>/`.
- Then tell the agent what to do, e.g. "analyze the refusal in Input/khan-spousal".
- The agent reads this folder and does not change or delete your files.
- Contents are ignored by git. Keep passports and other client ID scans out of this folder.
