## Current rules
### Completeness (IRPR s.10, s.12)
- Applications must be on the prescribed form, signed, with all required information, documents and **fees** (R10). Family class and other classes have extra completeness rules (R12) (M). Incomplete files are **returned** without processing (fees refunded).

### Top return/refusal triggers (by program)
| Program | Check before filing |
|---|---|
| All | Current form version; signatures; correct fees incl. RPRF/biometrics/OWP holder; IMM 5476 if represented; translations |
| Express Entry | Points proofs match profile; reference letters (duties, hours, salary); ECA level; language valid at e-APR; funds; police certificates; medicals |
| PNP | Nomination valid; matches EE profile |
| Spousal | Relationship evidence; IMM 5532; sponsor eligibility; in-Canada cohabitation; all dependants declared and examined |
| Study | LOA verified; PAL/TAL (2026 valid to 12-31); funds per table; study plan |
| Work | LMIA or offer number; job matches NOC; experience proof; employer compliance fee paid |
| PGWP | Language test; field of study; 180 days; passport validity |
| Citizenship | Presence calculator; 3 tax years; CIT 0002 current version |
| Asylum (C-12) | 1-yr / 14-day checks; complete within 60 days |
- **Missing document?** Explanation letter + proof uploaded in its slot (IRCC).
