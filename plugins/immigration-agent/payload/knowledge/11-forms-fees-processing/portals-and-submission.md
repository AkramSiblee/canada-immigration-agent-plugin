# Portals and submission

## Must cover
- Secure account, Representative Portal, e-signature, document rules

## Current rules
### Which account (IRCC page 2026-09-01)
| Application | Account |
|---|---|
| Visitor visa, super visa, transit | Secure account, IRCC portal, or new IRCC portal |
| Study permit | Secure account or IRCC portal |
| Work permit (incl. PGWP, IEC, extensions) | Secure account |
| **Express Entry** | Secure account |
| Other PR (non-EE PNP, family, AIP, pilots, business) | **Permanent residence portal** |
| PR card, PRTD | Permanent residence portal |
| Citizenship grant | Online citizenship application; certificate via secure account; e-certificate via IRCC portal |
| Asylum | IRCC portal |
- **Representatives**: Authorized Paid Representatives (APR) Portal for visitor visas, study and work permits, Express Entry, IEC, eTAs and IFHP; separate PR portal access for representatives. Always submit IMM 5476.
  - **One APR account per representative.** Sign in with GCKey or Sign-In Partner. Use a different GCKey for each portal.
  - Enrolment: complete the questions, print and sign **IMM 5661** (generated in the portal), upload it with two pieces of ID. Must be a full CICC member, not transitional.
  - Don't use the client's own portal. The representative must link the client's application to their account.

### Missing documents
- A missing required document can cause **delay, return or refusal**. If one is unavailable, upload a **letter of explanation + supporting proof** in its place. For police certificates, upload a letter of explanation and proof of best effort in the country field; an officer who isn't satisfied may reject the application as incomplete (IRCC page 2026-10-16, read 2026-11-09).

### Upload limits (IRCC Help Centre, 2026-11-03)
| Account | Limit per file | Accepted types |
|---|---|---|
| IRCC secure account | 4 MB | .jpg, .png, .doc, .tiff, .pdf |
| IRCC Portal and new version | 5 MB | .jpg, .png, .doc, .docx, .tiff, .pdf |
| Online citizenship application | 4 MB | .jpg, .jpeg, .png, .tif, .tiff, .pdf |
| Asylum portal | 4 MB | .jpg, .png, .tiff, .doc, .docx, .pdf |
| Permanent Residence Portal | 4 MB | .pdf for forms and supporting documents; .jpg, .jpeg, .doc, .docx, .png |

### Signatures
- **APR Portal:** on the "Your Declaration and Electronic Signature" page the representative selects I agree, enters their name, answers the security question and signs, then transmits and pays.
- **PR portal for representatives:** the client reviews and electronically signs in the client portal (typed signature on the consent and declaration and on the IMM 5669 web form); the representative then adds their declaration (M: IRCC search extract, page not read in full).

### Translations
- English or French translation plus translator's affidavit, unless the translator is certified. Include a copy of the original. See `05-temporary-residence/visitor-visa-documents.md`.

## Recent changes (2025-2027)
- New IRCC portal version in use (2026) (M)

## Consultant pitfalls
- Using the wrong portal for a program means it can't be submitted or is returned. Check the table.
- Upload one combined PDF per document slot, with the explanation letter first.

## Common refusal reasons
- Missing documents without explanation; unsigned forms; untranslated documents
