# Newfoundland and Labrador (NLPNP)

## Must cover
- Skilled Worker, Express Entry, International Graduate, Priority Skills; draw log; allocation; AIP

## Current rules
### Streams
- NLPNP Skilled Worker; NLPNP Express Entry Skilled Worker; NLPNP International Graduate; NLPNP International Entrepreneur; NLPNP International Graduate Entrepreneur
- **Priority Skills: not listed on current official pages.** Treat as discontinued or merged (baseline item not confirmed).
- Applications go through the **Immigration Accelerator** portal (NLPNP and AIP).

### EOI
- EOI model for all economic applications since **2025-02-19**. ITAs are issued in batches using prioritization criteria. Criteria are on the Prioritization Criteria page (not read).

### Fees / allocation
- Not found on official pages read (unresolved).

## Recent changes (2025-2027)
- 2025-02-19: EOI model for all economic streams (H)
- 2026: ITA volume tapering in Oct-Nov (25-131 per batch) (H)

## Consultant pitfalls
- No direct applications. EOI first via the Immigration Accelerator, then ITA.
- Batches are frequent but small late in the year. Expect allocation to be nearly used.
- Don't cite "Priority Skills NL" as an open stream.

## Common refusal reasons
- Job offer/employer criteria; NL connection; NOC not prioritized; language

## Re-verify before advising
- Prioritization criteria page; fees; 2026/2027 allocation; Priority Skills status
