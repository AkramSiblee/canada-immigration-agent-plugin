### Misrepresentation (IRPA s.40)
| Case | Application | Result | Point |
|---|---|---|---|
| *Domingcil*, **2026 FC 648** (2026-05-21) | Visitor extension; ID exclusion order | Upheld | Stated purpose was visiting his sister, while he had a job offer and LMIA. There is a duty to disclose material changes. A misrepresentation need not be decisive |
| *Singh*, **2025 FC 200** (2025-01-31) | TRV | Upheld | Omitted charges after "cutting and pasting" from an earlier form; similar omission in 2020. Short PFL was adequate because he understood it |
| *Himel*, **2025 FC 23** (2025-01-03) | Work permit | Upheld | Reference letter the employer did not give; he admitted not asking the employer |
| *Grobler*, **2025 FC 79** (2025-01-15) | Study permit | Set aside | Findings contradicted the evidence (expunged conviction). No sufficient rationale for rejecting innocent mistake |
| *Rafiq*, **2025 FC 160** (2025-01-28) | TRV | Set aside | Officer failed to engage with the PFL response on innocent mistake |
| *Amini*, **2024 FC 2052** (2024-12-17) | Work permit; fraudulent LMIA by consultant | Set aside | Officer misapprehended his submissions, including that he couldn't access his account to see the PFL. Innocent mistake not considered |

### Procedural fairness letters and credibility
| Case | Application | Result | Point |
|---|---|---|---|
| *Kaur*, **2026 FC 1216** (2026-10-01) | Visa cancelled; s.40 | Set aside | PFL stated a conclusion (report "confirmed to be fraudulent") without the underlying facts |
| *Rattol*, **2026 FC 1217** (2026-10-01) | Spousal OWP and study permit | Set aside | Saying a bank account was "inflated" is a credibility finding, so a chance to respond was required |
| *Li*, **2026 FC 697** (2026-05-29) | Work permit; s.40 | Set aside | Finding rested on documents only the employer could provide; no meaningful chance to respond |
| *Akaya*, **2026 FC 546** (2026-04-24) | Study permit | Set aside | Adverse credibility finding made without alerting the applicant |
| *Odobo*, **2026 FC 49** (2026-01-14) | Work permit; job offer genuineness | Set aside | Unfair PFL process |
| *Agyemang*, **2026 FC 30** (2026-01-09) | Study permit; bank statement | Set aside | Concerns and evidence were withheld; high fairness standard for s.40 |
| *Nguyen*, **2025 FC 1894** (2025-11-27) | Work permit; s.40 | Set aside | PFL lacked enough detail to know the case to meet |

### Study permit
| Case | Result | Point |
|---|---|---|
| *Juarez Lopez*, **2025 FC 1803** (2025-11-10) | Upheld (leave granted) | Officer may ask how the program benefits the applicant. Vague plans failed. Chinook use alone is not unreasonable |

- **Trend:** s.40 findings stand where the applicant controlled the information or gave an implausible explanation. They fall where the PFL hides the real concern, the officer ignores the response, or the concern lies outside the applicant's control.
- **C-12 retroactivity challenge:** none found (2026-11-07).

## Recent changes (2025-2027)
- 2025-11 to 2026-10: a run of decisions requiring PFLs to state the actual facts behind a s.40 concern (*Nguyen*, *Agyemang*, *Odobo*, *Kaur*) (H)

## Consultant pitfalls
- Use these themes in PFL responses and reconsideration requests. Refer JR to counsel.
- If a PFL is vague, say so in the response and ask for the facts.
- Update every family and background answer when reusing an old form (*Singh*).
- Keep clients' account access working, and warn them about consultants who don't share it (*Amini*).
