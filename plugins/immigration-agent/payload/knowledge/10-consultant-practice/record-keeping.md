# Record keeping

## Must cover
- Retention, file contents, privacy

## Current rules
- **Reliable office administration**. Records kept "in accordance with the by-laws" (Code s.37). Retention and disposal can be set by regulation (Act s.81(1)(w)). **Retention: minimum 6 years after the file is closed** (CICC Client File Management Regulation s.7.2) (H). The commonly cited "7 years" is wrong.
- **File contents** should include:
  - consultation and service agreements (Code s.23-24)
  - conflict disclosures and consents (s.15)
  - futile-application acknowledgements (s.27)
  - invoices, receipts and client-account ledger (s.32-33)
  - correspondence and status updates (s.22)
  - copies of all submissions, and the IMM 5476
  - termination accounting (s.36)
- **Confidentiality** indefinitely (Code s.28). SOR/2026-68 ss.41, 46-50 govern disclosure by the College and its committees, not a consultant's vendors (read in full 2026-11-09). See `ai-and-privacy.md`.
- Originals returned to the client (Code s.14).

### CICC Client File Management Regulation (2021-001), verified 2026-11-07
- File contents include: client authorization of a designate, drafts, copies of all applications/submissions; a property record (description, dates received and returned, client acknowledgement) (s.5).
- Store active and closed files separately (s.5.4); secure storage; agents must return client records per the Agent Agreement (s.6).
- **Close a file only when** fees/refunds are settled, property returned, and the client is notified in writing that the retainer ended and property was returned (s.7.1).
- **Retain 6 years after closing** (s.7.2); keep a closed-files list (s.7.3); record a projected destruction date (s.7.4).
- Client property: account within **14 days** and deliver within **30 days** of request (s.8.2).
- Destruction log: client name and address, service, closing date, destruction date; confidentiality maintained (s.10).
- Penalty for breach (s.12).

## Recent changes (2025-2027)
- SOR/2026-68 privacy and disclosure provisions in force 2026-07-15 (H)

## Consultant pitfalls
- Keep client-account records separate per client (s.32(d)).
- Cloud storage outside Canada: Code s.28, PIPEDA accountability and client consent apply. Quebec needs a privacy impact assessment first. See `ai-and-privacy.md`.
