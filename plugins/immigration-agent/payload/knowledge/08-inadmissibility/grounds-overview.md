# Inadmissibility grounds: overview

## Must cover
- ss.34-42 summary table and remedies

## Current rules
| IRPA | Ground | Applies to | Usual removal order (IRPR s.229) | Main remedies |
|---|---|---|---|---|
| s.34 | Security | PR + FN | Deportation | Ministerial relief s.42.1 |
| s.35 / 35.1 | Human/international rights; sanctions | PR + FN | Deportation | s.42.1 for 35(1)(b) |
| s.36(1) | Serious criminality | PR + FN | Deportation | Rehab (individual), record suspension, TRP |
| s.36(2) | Criminality | FN | Deportation (FN) | Deemed/individual rehab, TRP |
| s.37 | Organized criminality | PR + FN | Deportation | s.42.1 |
| s.38 | Medical | FN | Exclusion | Mitigation plan; exemptions (spouse/child/refugees) |
| s.39 | Financial | FN | Exclusion | Show funds; protected persons exempt |
| s.40 | Misrepresentation | PR + FN | Exclusion (5-yr ARC) | Wait 5 yrs; innocent mistake; IAD for spouse/child; + AMP |
| s.41 | Non-compliance | PR + FN | Exclusion/departure | Restoration, TRP, H&C |
| s.42 | Inadmissible family member | FN | Exclusion | Separate family member; H&C |
- Standard of proof: "**reasonable grounds to believe**" for ss.34-37 (s.33).
- No IAD appeal for security, rights, sanctions, serious criminality (6+ months imposed), organized crime (s.64).
- H&C (s.25) can overcome most grounds **except** ss.34, 35, 35.1, 37 (s.25(1)).

## Recent changes (2025-2027)
- 2026-10-23: AMPs for misrepresentation (SOR/2026-220) (H)

## Consultant pitfalls
- Screen every client for all grounds at intake (use the case-intake skill). Hidden criminality, health issues and prior refusals are the biggest risks.
- Remedies differ by ground. Choose rehab vs TRP vs H&C carefully.
