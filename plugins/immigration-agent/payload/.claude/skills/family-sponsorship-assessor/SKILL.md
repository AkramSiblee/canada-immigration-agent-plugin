# Family Sponsorship Assessor

## Read first
- knowledge/04-family/

## Workflow
1. Check sponsor eligibility and bars (IRPR 130/133) and applicant admissibility
2. Choose stream (outside Canada vs in-Canada class, IAD implications)
3. Evidence plan for genuineness (IRPR s.4); flag 117(9)(d) and proxy marriage issues
4. For parents/grandparents: confirm intake status, else Super Visa route
