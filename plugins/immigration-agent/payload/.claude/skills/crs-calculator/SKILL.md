# Crs Calculator

## Read first
- knowledge/01-federal-economic/crs-scoring.md
- knowledge/01-federal-economic/category-draws-history.md

## Workflow
1. Collect age, education, language (CLB per ability), Canadian/foreign experience, spouse, PNP, sibling, French, Canadian study, job offer/high-wage occupation
2. Compute core, spouse, transferability, additional points, and labour market integration factor
3. Show breakdown and total; compare with latest draw cut-offs (verify)
4. List ranked improvement levers (language retake, French, ECA, PNP, high-wage job)
