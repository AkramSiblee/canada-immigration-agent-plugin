# Output
The agent saves finished work here: advice memos, letters, checklists, fee and CRS calculations.

- Location: `Output/<same subfolder name as Input>/`, or `Output/general/` when there is no client.
- File names: `YYYY-MM-DD-<document-type>.<ext>`, e.g. `2026-11-08-refusal-analysis.md`.
- Only documents a person reads belong here, such as PDF, Word or Excel. No JSON, CSV, logs or other technical files.
- Everything here is a draft for the consultant's review before it goes to a client or IRCC.
- Contents are ignored by git.
